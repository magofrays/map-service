# map-service
Для использования нужно в src/main/resources/map положить карту с OpenStreetMap и назвать её в соответствии с docker-compose.
### Cервис предоставляет:
- Постройка маршрута между двумя точками
- Добавление точек на карту и получение этих точек в радиусе координаты
- Генерация маршрута по точкам, которые уже есть в сервисе и сохранение его в бд
